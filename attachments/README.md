# Attachments
Put drawings, screenshots, résumé PDF and portrait data here. Use relative paths such as `attachments/sketch-01.jpg` in region items.

Optional `portrait.json`: `{ "points": [[x,y,z], ...], "triangles": [[0,1,2], ...] }`. Coordinates should be centred near the origin and approximately 400 units high, with negative Y at the top and positive Z facing the visitor. Without this file, a generic faceted bust is shown. It is explicitly not your likeness.
